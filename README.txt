نسخه آماده GitHub Pages

فایل index.html و پوشه assets را کنار هم در ریشه محل انتشار سایت قرار دهید.
اگر GitHub Pages از پوشه docs منتشر می‌شود، هر دو را داخل docs قرار دهید.
پوشه assets را نیز کامل آپلود کنید؛ مسیرها نسبی و به بزرگی و کوچکی حروف حساس هستند.

۹ عکس اصلی با کیفیت اصلی استخراج شده‌اند و favicon نیز به فایل SVG جدا تبدیل شده است.
عکس‌های پروژه‌ها به صورت lazy بارگذاری می‌شوند. عکس معرفی در بارگذاری اولیه باقی می‌ماند.
این نسخه تصاویر را حذف نکرده است؛ تصاویر به فایل‌های جدا منتقل شده‌اند.
گالری موبایل: کشیدن به چپ برای تصویر بعدی و به راست برای تصویر قبلی؛ نقطه‌ها نیز فعال هستند. اسکرول عمودی و زوم با دو انگشت حفظ شده‌اند.
